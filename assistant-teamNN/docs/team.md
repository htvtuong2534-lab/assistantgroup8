## Branch Workflow

Each team member works on their assigned branch.

```text
Member
   ↓
Personal branch
   ↓
Commit
   ↓
Push
   ↓
Pull Request
   ↓
main
```

Members should push their work to their own branch. Changes are merged into `main` through Pull Requests.
